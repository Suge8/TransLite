# Privacy Policy

Effective date: 2026-06-02

TransLite is a browser extension for translating web pages and YouTube subtitles.

## Data TransLite processes

TransLite may process:

- page text you choose to translate
- YouTube subtitle text you choose to translate
- extension settings, such as language, translation mode, provider, site rules, and shortcuts
- API keys or provider settings that you enter yourself

## How data is used

TransLite uses this data only to provide translation features and save your settings.

When you translate content, the text is sent to the translation provider you choose, such as Google Translate, DeepL, DeepSeek, OpenAI, Gemini, OpenRouter, Ollama, or an OpenAI-compatible service.

TransLite does not sell user data, use ad tracking, or use data for credit decisions.

## Local storage

Settings are stored locally in your browser. TransLite does not operate its own account system or analytics backend.

## Third-party providers

Translation providers process translated content under their own terms and privacy policies. If you configure a custom provider or API key, you are responsible for that provider choice.

## Contact

For support or privacy questions, use the project issue tracker or support channel linked from the Chrome Web Store listing.
